# NAVOSYS Approved Website Theme

**Theme:** Warm Ivory + Sand + Deep Navy + Muted Teal + Warm Gold
**Design personality:** premium, sophisticated, trustworthy, calm, warm and modern.

| Token | HEX | Intended role |
|---|---|---|
| Warm Ivory | `#FAF8F5` | Dominant page background |
| Sand | `#E9E4DC` | Cards, secondary/alternating sections |
| Deep Navy | `#23364D` | Headlines, navigation, footer, dark surfaces |
| Muted Teal | `#6F9690` | Primary CTA and selected accents, contrast-tested |
| Warm Gold | `#C89F79` | Small decorative highlights |

## Principles
- Warm Ivory is the primary canvas; Sand adds section variation.
- Deep Navy anchors typography and navigation.
- Muted Teal is used for conversion actions and select accents, with contrast-safe variants as needed.
- Warm Gold is used sparingly and is not a default text or CTA color.
- Maintain generous whitespace, simple typography, understated borders/shadows, restrained motion and clear hierarchy.
- Avoid excessive gradients, neon/futuristic styling, generic robot imagery and clutter.
- Test contrast, focus states, responsive layouts and reduced-motion support. Color is never the only state indicator.
- Centralize tokens; avoid scattered hardcoded colors.

This reference is subordinate to and consistent with M0; P03 is responsible for implementation and verification.
