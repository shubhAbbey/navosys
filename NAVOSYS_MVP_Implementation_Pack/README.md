# NAVOSYS Website MVP Implementation Pack

This package contains the master specification and sequential phase briefs for Anti-Gravity.

## Start here
1. Read `master/M0_MASTER_SPECIFICATION.md` completely.
2. Read `phases/P01...` and execute P01 only.
3. User manually creates the GitHub repository and connects the project/remote.
4. Anti-Gravity creates the project and structure, and commits/pushes only when connected and authorized.
5. After phase report and human review, provide the next phase file.

## Official visual theme
- Warm Ivory `#FAF8F5`
- Sand `#E9E4DC`
- Deep Navy `#23364D`
- Muted Teal `#6F9690`
- Warm Gold `#C89F79`

This approved palette is specified in M0 and mandatory in P03.

## Contents
- `master/M0_MASTER_SPECIFICATION.md`: permanent governing rules
- `phases/`: sequential implementation briefs P01-P19

## Important
- CMS is the source of truth for public content.
- All production images are Strapi assets.
- Pages/routes are CMS-resolved, not hardcoded content pages.
- Primary CTA is Get a Quote; Book a Consultation is secondary.
- Lead submission backend is secured and lead records are not publicly exposed.
- Keep frontend lightweight, server-first and minimal.
