# Repository Structure

This repository follows the simple structure defined in `M0_MASTER_SPECIFICATION.md`:

- `apps/web/`: Next.js App Router frontend (`app/`, `components/`, `lib/`, `styles/`, `types/`, `tests/`).
- `cms/`: Reserved for Strapi 5 CMS project initialization in **P02**.
- `infrastructure/docker/` & `infrastructure/deployment/`: Reserved for containerization, reverse proxy, and deployment configuration in later phases.
- `docs/`: Technical documentation, phase implementation reports, asset plans, and deployment runbooks.
- `scripts/`: Reserved for maintenance, seeding, and verification scripts in later phases.
- `NAVOSYS_MVP_Implementation_Pack/`: Authoritative specification pack preserved unmodified.
